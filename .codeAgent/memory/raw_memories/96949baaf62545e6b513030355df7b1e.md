## Build/test commands documented
Prefer Gradle wrapper. On Windows use `./gradlew.bat`; on Unix-like shells use `./gradlew`.
- Compile Kotlin only: `./gradlew.bat compileKotlin`
- Run all tests: `./gradlew.bat test`
- Run one known test class example: `./gradlew.bat test --tests com.tang.intellij.test.inspections.GeneratedEmmyAnnotationInspectionTest`
- Build plugin for default target: `./gradlew.bat buildPlugin`
- Build for specific target: `./gradlew.bat buildPlugin -DIDEA_VER=231`
- Publish requires `IDEA_PUBLISH_TOKEN`: `./gradlew.bat publishPlugin`

## Coding and IntelliJ plugin guidance captured
- Preserve existing concise Kotlin style and IntelliJ Platform idioms; avoid broad rewrites.
- Use Kotlin for new plugin logic unless surrounding code is Java or generated code.
- Keep package names under `com.tang.intellij.lua` or matching existing package.
- When changing extension behavior, update descriptors in `src/main/resources/META-INF` and add/update tests where possible.
- For completion, inspections, intentions, refactoring, formatter, PSI/stub, or type inference changes, look for an existing focused test under `src/test/kotlin/com/tang/intellij/test` before adding a new class.
- For tests using inline Lua snippets, follow fixture style in `LuaTestBase`, `LuaInspectionsTestBase`, and completion test bases; larger fixtures go in `src/test/resources` near similar cases.
- Check `git status --short` before non-trivial edits; do not overwrite user changes in a dirty worktree.
- Gradle patches plugin version/build compatibility during packaging, so do not rely only on XML `idea-version` in `plugin.xml`.

## LuaDoc / EmmyLua convention preserved
- Newly generated LuaDoc field annotations should use `---@field name type`, **not** `---@field public name type`.
- Parser compatibility should remain for legacy annotations like `---@field public name type`.
- When touching LuaDoc annotation generation or completion, inspect related files such as `LuaCommentUtil.kt`, `LuaDocCompletionContributor.kt`, tutorial/file templates, and `GeneratedEmmyAnnotationInspectionTest.kt`.
